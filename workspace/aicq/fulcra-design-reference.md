# Fulcra design cues for AICQ

User direction: use Context Web design cues and the Fulcra logo. Both local HTML
studies now follow that direction. AICQ remains the product name.

Canonical assets and full guide snapshot: `design-references/fulcra/`.
Local guide: `docs/design-references/fulcra/README.md`; source hashes:
`docs/design-references/fulcra/manifest.json`.

Guide: https://github.com/kubla/fulcra-design-reference/blob/3f54e39d927b2d954897b82b9ba8ba315ea283ab/context-web/DESIGN.md
Logo: https://github.com/ashfulcra/fulcra-tools/blob/c67aa1accbb9ffc7a0a3ab81ea20c21de6969e16/packages/menubar/fulcra_menubar/assets/source/fulcra-logo.svg

Use Rubik, mint ordinary actions, violet selection, flat charcoal surfaces,
compact controls, subtle dividers and hexagonal identity avatars. Preserve the
original Fulcra mark geometry; monochrome in native navigation, mint beside
AICQ inside app content. Host chrome follows `host-ui-reference.md`, with system
fonts and native composer/context controls. Keep simulation controls outside it.

These are simulated local prototypes. Narrow host layout is extrapolated;
installed-client appearance, live rendering and product acceptance remain open.
Full evaluation and screenshots: `prototypes/fulcra-evaluation.md` and
`prototypes/fulcra-evaluation.json`. History: `history/20261003_fulcra-prototype.md`.
